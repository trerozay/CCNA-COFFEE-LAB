# LinkedIn Post Draft

I’m excited to share my latest Cisco Packet Tracer project: a segmented network for a small coffee shop.

In this lab, I configured:

- VLANs for office, corporate Wi-Fi, guest Wi-Fi, and management
- Router-on-a-stick and 802.1Q trunking
- DHCP pools and wireless connectivity
- An extended ACL that isolates guest devices from internal resources
- Basic switch security and connectivity testing

This project strengthened my hands-on skills in VLANs, routing, ACLs, wireless networking, and troubleshooting as I continue preparing for the CCNA.
